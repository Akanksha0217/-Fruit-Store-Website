# 🍎 Fruit Store Website (React.js)

🚀 A responsive **Fruit Store Web App** built using **React.js**, **CSS**, and **Bootstrap**, allowing users to browse, filter, and add fruits to a shopping cart.

---

## 🌐 Live Demo
🔗 **Live Website:** [fruitstorereact.netlify.app](https://fruitstorereact.netlify.app/)  
💻 **GitHub Repository:** [github.com/Akanksha0217/FruitStoreReact](https://github.com/Akanksha0217/FruitStoreReact)

---

## 🧠 Features
- 🛒 Browse a list of fruits with images, names, and prices  
- ➕ Add and remove items from the cart  
- 🔄 Update item quantity dynamically  
- 🔍 Search and filter fruits by name or category  
- 💾 Persistent cart using `localStorage`  
- 📱 Fully responsive design using **Bootstrap**

---

## 🛠️ Tech Stack
| Technology |      Description |
|-------------|    -------------|
| **React.js** | Frontend framework for building UI |
| **CSS3 / Bootstrap** | Styling and responsiveness |
| **JavaScript (ES6+)** | Application logic |
| **LocalStorage** | Save cart data persistently |
| **Netlify** | Deployment platform |

---
## 🧩 How It Works
1. Users can view all fruits on the homepage.  
2. Click **Add to Cart** to include items in the shopping cart.  
3. Items appear in the cart with total price calculation.  
4. Cart updates dynamically (add/remove/increase/decrease).  
5. Data is saved in `localStorage` so it persists after reload.
